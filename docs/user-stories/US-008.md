# US-008 — Build company selection and tenant-safe switching

**Epic:** [E01 #2](https://github.com/wdmahbubur/accounts-management-solution/issues/2)  |  **Milestone:** M1 — Secure foundation  |  **Priority:** P0

- [ ] A user belonging to both companies still cannot link A documents to B accounts.

## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-03 — Company switcher and company list
**Routes:** `/companies`
**Access:** Active membership
**Structure:** Company cards/table with legal/display name, membership role and onboarding/read-only status. Persistent current-company indicator after selection.
**Actions:** Open company, create company, leave allowed membership.
**Validation:** Creating a company follows entitlements; final owner cannot leave without transfer. Clear company-specific caches on switch.
**Expected outcome:** Switching companies updates all navigation, searches, report filters and pending form context without mixing balances.
