## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-11 — Service/non-stock catalogue
**Routes:** `/o/[org]/catalog/items`
**Access:** catalog.read/write
**Structure:** Item/service table with SKU, name, unit, default selling price, revenue/purchase account, tax and active state; editor drawer.
**Actions:** Add/edit/archive, CSV import.
**Validation:** Explicit non-stock scope; no stock quantity or margin claims. Used historical descriptions and amounts remain snapshots.
**Expected outcome:** Selecting an item populates defaults but server validates and snapshots the final invoice line.
