### UI-26 — Bank-account ledger/detail
**Routes:** `/o/[org]/banking/accounts/[id]`
**Access:** banking.read
**Structure:** Opening/closing balance, transaction-date range, debit/credit/running balance, reference, source link, match status; tabs Ledger/Statements/Reconciliations.
**Actions:** Open source, filter unmatched, export cashbook.
**Validation:** Running balance uses deterministic ordering; current/book balance labels differ from statement balance.
**Expected outcome:** Opening + money in − money out equals closing under the selected filters.
