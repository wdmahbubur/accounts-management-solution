## Acceptance criteria
- [ ] One transaction creates organization, owner membership, roles, approved default COA, mappings and periods.
- [ ] Collect company name, country, BDT currency, timezone, fiscal start and books-start date.
- [ ] Retry onboarding without duplicate companies or partially seeded accounting configuration.
- [ ] Reject unsupported currency and roll back all defaults on failure.

### UI-04 — Company setup wizard
**Routes:** `/onboarding/company`
**Access:** Company creator / owner
**Structure:** Steps: company identity → fiscal calendar and books start → template COA → bank/cash → tax preferences → invite team → review. Save progress between steps.
**Actions:** Back, continue, save draft, finish setup.
**Validation:** BDT-only with explicit label; fiscal range validation; required system mappings; first-post restrictions preview.
**Expected outcome:** Finishing creates one complete tenant setup; repeated submission does not duplicate roles/accounts.
