# US-016 — Implement accounting dates, fiscal periods and shared lock protocol

**Epic:** [E02 #3](https://github.com/wdmahbubur/accounts-management-solution/issues/3)  |  **Milestone:** M2 — Tested accounting engine  |  **Priority:** P0

## User story
As a **accountant**, I want to **stop backdated activity from bypassing closed books**.

## Acceptance criteria
- [ ] Resolve accounting date to a valid fiscal period and enforce books-start boundaries.
- [ ] All posting, settlement, unapply, import and reversal commands share a transaction-safe period lock protocol.
- [ ] Concurrent close either follows a committed financial operation or blocks it cleanly.
- [ ] Keep close/reopen events append-only and require reason plus elevated recent-auth permission.
