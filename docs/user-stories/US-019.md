# US-019 — Implement permanent document numbering and idempotent commands

**Epic:** [E02 #3](https://github.com/wdmahbubur/accounts-management-solution/issues/3)  |  **Milestone:** M2 — Tested accounting engine  |  **Priority:** P0

## User story
As a **finance user**, I want to **retry safely without duplicate vouchers or journals**.

## Acceptance criteria
- [ ] Allocate unique company/type/fiscal numbering inside the financial transaction.
- [ ] Same key plus same request returns original result and changed payload returns conflict.
- [ ] Different keys racing on the same source still produce at most one journal.
- [ ] Handle transient deadlocks with bounded whole-transaction retry and preserve permanent numbers after reversal.
