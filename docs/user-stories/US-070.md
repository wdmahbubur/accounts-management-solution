## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-46 — Imports and export jobs
**Routes:** `/o/[org]/imports; /imports/[id]; /exports`
**Access:** imports.read/run; exports.read
**Structure:** Job list with type, state, row counts, errors, created by, timestamps; mapping/error grid; export filter/snapshot summary and expiry.
**Actions:** Upload/validate/retry safe rows, download row errors, request report export, download authorized completed file.
**Validation:** Opening financial batch is all-or-nothing; master-data import can use explicitly reported row-level progress. Download rechecks current permission.
**Expected outcome:** Retry cannot duplicate imports and expired/revoked exports do not leak private data.
