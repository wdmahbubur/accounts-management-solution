## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-36 — Report hub
**Routes:** `/o/[org]/reports`
**Access:** reports.read with report-specific capabilities
**Structure:** Grouped Financial statements, Dues, Banking, Activity; descriptions, date semantics and provisional labels; recent export jobs.
**Actions:** Open report, choose date range/as-of, view export history.
**Validation:** Hide reports lacking capability; no unsupported future-report placeholders that appear functional.
**Expected outcome:** User can identify P&L period reports versus balance-sheet as-of reports.
