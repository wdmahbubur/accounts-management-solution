## Acceptance criteria
- [ ] Claim jobs with bounded leases, retry/backoff and dead-letter visibility.
- [ ] Use stable event IDs and provider idempotency where available for at-least-once work.
- [ ] Worker crash or renderer failure never reverses/reposts the committed journal.
- [ ] Restrict worker data access to the event organization and record safe failure metadata.
