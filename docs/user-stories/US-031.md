## Acceptance criteria
- [ ] Earned invoice debits AR and credits earned revenue plus applicable approved tax.
- [ ] Future-service/deferred invoice uses configured liability treatment instead of premature revenue.
- [ ] Posted detail shows source journal, approval, residual, correction links and independent delivery state.
- [ ] Reject unauthorized, stale, closed-period or incomplete recognition inputs.

## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-14 — Invoice detail
**Routes:** `/o/[org]/sales/invoices/[id]`
**Access:** sales.read
**Structure:** Immutable preview, source/settlement/delivery status strip, total and balance; tabs Details, Payments/Credits, Attachments, Activity, Accounting (permissioned).
**Actions:** Send/resend, export PDF, record collection, issue credit, request reversal.
**Validation:** Financial edit action absent after posting. Reverse shows affected allocations and locked-period restrictions.
**Expected outcome:** The PDF and UI show the original issued contact/tax snapshot; all linked settlements explain residual balance.

## Database/accounting guards
- [ ] [DB-G01](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Balanced complete journal:** Posting function plus deferred constraint trigger: ≥2 lines, positive debits, debit=credit, state posted at commit.
- [ ] [DB-G02](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Source/journal agreement:** Exactly one journal per posted source; source type, accounting date, currency, period and totals agree; no journal for an unposted/void source.
- [ ] [DB-G06](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Complete subledger:** Each control ledger line has one matching open item; other ledger lines have none; same party/account/amount/side.
- [ ] [DB-G10](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Approval validity:** Expected source version/digest and policy snapshot must match; authorized approver; maker-checker; approval invalidated by material edits.
- [ ] [DB-G12](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Tax/totals:** Recompute line/header totals, recognition mode, original credit-line references/caps, non-overlapping tax versions, snapshot/recovery policy and explicit rounding; never trust client-calculated totals.
