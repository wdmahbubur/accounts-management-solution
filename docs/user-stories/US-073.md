## UI contract
These are shared screen groups. Implement the portions required by this story; related stories own the remaining behavior. All affected screens need loading, empty, validation, forbidden and conflict states and keyboard-accessible controls.

### UI-52 — Notification center
**Routes:** `/o/[org]/notifications`
**Access:** Authenticated authorized member
**Structure:** Actionable approvals, due items, failed delivery/export and closing exceptions with source links; read/unread state may be implemented as user-level preference later.
**Actions:** Open authorized source, retry permitted failed delivery, dismiss presentation notice.
**Validation:** No confidential amounts in unauthenticated push/email previews; delivery failure never changes posting state.
**Expected outcome:** A failed invoice email can be retried without posting the invoice again.

2. Use a branch such as `feat/us-NNN-short-title`. Make reviewed versioned migrations where needed; preserve unrelated code and source documents.
