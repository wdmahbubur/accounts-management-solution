## Acceptance criteria
- [ ] Require distinct eligible source/destination accounts, amount, accounting date and reference.
- [ ] Post both principal legs and any separately coded fee atomically.
- [ ] Internal cash-equivalent principal is excluded from external cash-flow totals while fees remain classified.
- [ ] Retry safely and reject insufficient physical cash, wrong tenant, same account and locked period.

### UI-27 — Transfers
**Routes:** `/o/[org]/banking/transfers; /transfers/new; /transfers/[id]`
**Access:** banking.read/write
**Structure:** From/to accounts, principal, optional fee and fee account, date/reference, preview of both legs.
**Actions:** Save, approve, post transfer.
**Validation:** Same account prohibited; prevent insufficient physical cash where configured; classify non-equivalent destinations correctly.
**Expected outcome:** Either all legs/fee post or none do; no fake income is created.

## Database/accounting guards
- [ ] [DB-G01](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Balanced complete journal:** Posting function plus deferred constraint trigger: ≥2 lines, positive debits, debit=credit, state posted at commit.
- [ ] [DB-G04](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Locked-period safety:** Lock/check fiscal year and period before posting or settlement; period-lock command uses compatible lock order so race cannot bypass close.
- [ ] [DB-G10](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Approval validity:** Expected source version/digest and policy snapshot must match; authorized approver; maker-checker; approval invalidated by material edits.
- [ ] [DB-G11](https://github.com/wdmahbubur/accounts-management-solution/blob/master/docs/03-database-design.md) **Cash constraints:** Cash-account mapping matches GL line; avoid negative configured physical cash under concurrent spend; internal transfer legs/classification agree.
