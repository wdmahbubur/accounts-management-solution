## Acceptance criteria
- [ ] Write actor, organization, source version, action, reason and safe before/after metadata with the mutation.
- [ ] Outbox event creation is in the same transaction as posting with stable event IDs.
- [ ] Do not log passwords, tokens, full sensitive attachments or unrelated-company data.
- [ ] Audit records cannot be edited/deleted by ordinary users or silently replaced by delivery retries.
